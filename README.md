# Checker-Game

A desktop Checkers game built in **Java Swing**, featuring both **human vs human** and **human vs AI** gameplay.  
The AI opponent is powered by the **Minimax algorithm** with a heuristic evaluation function for smarter moves.

---

## 🎮 Features
- ✅ 8×8 playable Checkers board with Red and Black pieces.  
- ✅ Human vs AI mode (default: Human = Red, AI = Black).  
- ✅ King mechanics (promotion to King when reaching the far row).  
- ✅ Diagonal jumps and captures supported.  
- ✅ Restart button and game status display.  
- ✅ Game over detection with winner announcement.  

---
